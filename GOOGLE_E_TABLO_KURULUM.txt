SHAZ v31 — GOOGLE E-TABLO OTOMATİK KALICI SİPARİŞ KAYDI

AMAÇ
Müşteri siparişi tamamladığı anda, manuel Excel indirmeye gerek kalmadan sipariş Google E-Tablo'ya yazılır.
Google E-Tablo ana operasyon kaydıdır. Render yeniden deploy olsa bile bu kayıt kaybolmaz.

EXCEL/E-TABLO DÜZENİ
Her müşteri tam 8 satır:
1) Ad Soyad
2) Telefon (ikinci telefon yazılmaz)
3) Açık adres
4) İl + İlçe
5) Tutar + "TL"
6) Kapıda nakit / havale
7) @
8) Ürün adı + varsa çıkarılan ürün + varsa kişiselleştirme

Sağ taraf:
B = SİPARİŞ
C = ADET (bir hazır set = 1)
D = HAZIR MI
E = KARGOYA VERİLDİ Mİ

Hazır sette "Saat + Çakmak + ..." diye parçalama yapılmaz.
Örn:
3'lü Özel Set | Çıkarılan: Kemer | Yazı: Çakmak: Erdal (Ön yüz)

KURULUM
1. Google Drive'da yeni bir Google E-Tablo oluştur.
   İsim önerisi: SHAZ Siparişler

2. E-Tablo içinde:
   Uzantılar > Apps Script

3. Açılan editördeki mevcut kodu sil.
   Bu paketteki "google-apps-script.gs" dosyasının tamamını yapıştır.

4. Apps Script ekranında:
   Project Settings / Proje Ayarları > Script Properties / Komut dosyası özellikleri
   Yeni özellik ekle:
   Property: SHAZ_WEBHOOK_SECRET
   Value: kendin uzun rastgele bir gizli değer üret.
   BU DEĞERİ KİMSEYLE PAYLAŞMA.

5. Deploy > New deployment > Web app
   Execute as: Me
   Who has access: Anyone
   Deploy.
   Google izin ekranını onayla.
   Sana ".../exec" ile biten Web app URL verecek. Kopyala.

6. Render > SHAZ > Environment içine iki değişken daha ekle:
   GOOGLE_SHEETS_WEBHOOK_URL = Apps Script'in .../exec adresi
   GOOGLE_SHEETS_SECRET = 4. adımda oluşturduğun gizli değer

7. Save, rebuild, and deploy.

- Sipariş başarılı mesajı geldiyse Google E-Tablo'da 8 satırlık blok oluşmuş olmalı.

ÖNEMLİ
Bu sürümde sipariş Google E-Tablo'ya yazılamazsa müşteriye sipariş başarılı gösterilmez.
Böylece "panelde gördüm sandık ama kalıcı yere yazılmadı" durumu oluşmaz.

Google E-Tablo siparişler için kalıcı ana kayıt olur.
Render'daki orders.json yönetim panelinin hızlı yerel kopyasıdır ve deploy'da sıfırlanabilir.

V61 KONTROL
- Yönetim paneli > Siparişler > “E-Tablo Bağlantısını Test Et” butonuna bas.
- “Geçersiz işlem.” görürsen Apps Script eski sürümdür: google-apps-script.gs dosyasını yapıştır, Deploy > Manage deployments > Edit > New version > Deploy yap.
- “Yetkisiz istek.” görürsen Apps Script > Script Properties içindeki SHAZ_WEBHOOK_SECRET ile Render GOOGLE_SHEETS_SECRET aynı değildir.
- “GOOGLE_SHEETS_WEBHOOK_URL eksik” görürsen Render Environment URL değişkenini ekle.
- Test başarılıysa bekleyen siparişlerde “E-Tablo'ya Şimdi Gönder” butonuna bas; otomatik senkron da 60 saniyede bir çalışır.
